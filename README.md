# Simple IPN

**Sell digital downloads with PayPal. Deliver automatically.**

Free, self-hosted PHP PayPal IPN handler.

Live: https://ram133.github.io/simple-ipn/

## Use cases

- Ebooks & PDFs
- Prompt packs
- Templates & design assets
- Software keys / license delivery

## Why

Most digital delivery platforms take a cut or charge monthly. Simple IPN runs on your own host and only uses PayPal’s free IPN system.

## Status

Core PHP IPN listener + delivery logic. Open source.

Built with Grok.
